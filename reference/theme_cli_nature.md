# Nature Publishing Group Theme

Open axes with outward ticks and zero gridlines conforming to Nature and
Nature Communications figure guidelines.

## Usage

``` r
theme_cli_nature(base_size = 10, base_family = "")
```

## Arguments

- base_size:

  Base font size in points (default 11).

- base_family:

  Base font family.

## Value

A ggplot2 theme.
