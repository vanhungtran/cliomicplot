# Nature Pathology Boxplot Theme

Open L-frame axes, outward ticks, dotted horizontal y-gridlines, and
publication typography conforming to Nature Aging / SciFig boxplot
standards (as seen in Yadav et al. 2026).

## Usage

``` r
theme_cli_pathology(base_size = 8, base_family = "")
```

## Arguments

- base_size:

  Base font size in points (default 11).

- base_family:

  Base font family.

## Value

A ggplot2 theme.
