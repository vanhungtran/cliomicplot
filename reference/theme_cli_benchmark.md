# Benchmark & Multi-Omics Figure Theme

Open L-frame axes (top and right spines removed), crisp black axis
lines, outward ticks, frameless legend, and clean white background
without gridlines. Adheres to the figures4papers / Chen Liu publication
style used in leakage-controlled multi-omics and drug target
prioritization benchmarks.

## Usage

``` r
theme_cli_benchmark(base_size = 10, base_family = "")
```

## Arguments

- base_size:

  Base font size in points (default 11).

- base_family:

  Base font family.

## Value

A ggplot2 theme.
