# Helper builder for cross-network layers

Helper builder for cross-network layers

## Usage

``` r
build_cross_network_layers(
  custom_data,
  level,
  groups,
  layout,
  module_colors,
  cross_colors,
  show_hulls,
  hull_alpha,
  show_meta,
  node_size_range,
  edge_color,
  edge_alpha,
  edge_width,
  cross_width,
  cross_alpha
)
```
