# Helper builder for cross-network layers

Helper builder for cross-network layers

## Usage

``` r
build_cross_network_layers(
  custom_data,
  level,
  color_by = NULL,
  groups = NULL,
  group_colors = NULL,
  layout = "triangle",
  module_colors = NULL,
  cross_colors = NULL,
  show_hulls = TRUE,
  hull_alpha = 0.18,
  show_meta = TRUE,
  node_size_range = c(1.2, 4.2),
  edge_color = "grey85",
  edge_alpha = 0.45,
  edge_width = 0.2,
  cross_width = 0.6,
  cross_alpha = 0.75,
  show_module_labels = NULL,
  module_labels = NULL,
  module_label_size = 2.6,
  module_label_color = "grey15",
  module_label_fill = "white",
  module_label_bg = TRUE,
  meta_label_size = 3.2,
  meta_label_color = "grey15",
  module_size_range = c(3.5, 8.5),
  circle_radius = 1.05,
  preset = "default"
)
```
