# Helper builder for cross-network layers

Helper builder for cross-network layers

## Usage

``` r
build_cross_network_layers(
  custom_data,
  level,
  groups,
  layout,
  module_colors,
  cross_colors,
  show_hulls,
  hull_alpha,
  show_meta,
  node_size_range,
  edge_color,
  edge_alpha,
  edge_width,
  cross_width,
  cross_alpha,
  show_module_labels = NULL,
  module_labels = NULL,
  module_label_size = 2.6,
  module_label_color = "grey15",
  module_label_bg = TRUE
)
```
