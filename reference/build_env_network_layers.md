# Helper builder for env network layers

Helper builder for env network layers

## Usage

``` r
build_env_network_layers(
  custom_data,
  env_cors,
  links,
  module_colors,
  corner_palettes,
  link_colors,
  resolved_label_type,
  value_digits,
  value_size,
  compact,
  show_module_labels = TRUE,
  module_labels = NULL,
  module_label_size = 2.8,
  module_label_color = "grey15",
  module_label_bg = TRUE,
  module_label_alpha = 1,
  module_label_pos = "radial",
  curvature = 0.14,
  circle_radius = 2.45
)
```
