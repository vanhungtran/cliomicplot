# SCI Full-Box Scientific Figure Theme

Implements the SCI/Elsevier/IEEE scientific figure theme with 4 crisp
spines, outward tick marks, and subtle reference grid.

## Usage

``` r
theme_cli_scifig(base_size = 8, base_family = "")
```

## Arguments

- base_size:

  Base font size (default 8).

- base_family:

  Font family (default "").

## Value

A ggplot2 theme.
