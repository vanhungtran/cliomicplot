# Grammar Layer: Central Network Circular Boundary Ring

Draws the circular boundary ring enclosing the central network and the
outer concentric dots defining the open annular link corridor.

## Usage

``` r
geom_env_boundary(
  data = NULL,
  circle_radius = 2.8,
  circle_width = 0.4,
  circle_color = "grey65",
  circle_linetype = "dashed",
  outer_ring_size = 0.6,
  outer_ring_color = "grey60",
  outer_ring_alpha = 0.6
)
```

## Arguments

- data:

  Optional `cli_env_network_data` object generated by
  [`cli_env_network_data`](https://vanhungtran.github.io/cliomicplot/reference/cli_env_network_data.md).
  If NULL, default boundary dimensions are computed automatically.

- circle_radius:

  Numeric radius of the central boundary circle (default 2.80).

- circle_width:

  Line width of the central boundary circle (default 0.4).

- circle_color:

  Color of the central boundary circle (default `"grey65"`).

- circle_linetype:

  Linetype of the central boundary circle (default `"dashed"`).

- outer_ring_size:

  Size of dots along the outer boundary ring (default 0.6).

- outer_ring_color:

  Color of dots along the outer boundary ring (default `"grey60"`).

- outer_ring_alpha:

  Transparency of dots along the outer boundary ring (default 0.6).

## Value

A list of `ggplot2` layers.
