# Showcase Theme for High-Contrast Posters & Hero Figures

Showcase Theme for High-Contrast Posters & Hero Figures

## Usage

``` r
theme_cli_showcase(base_size = 12, base_family = "")
```

## Arguments

- base_size:

  Base font size in points (default 11).

- base_family:

  Base font family.

## Value

A ggplot2 theme.
