# Ecology / Demographic Viability Theme

Full 4-sided black frame, clean white background without gridlines,
outward tick marks, and bold axis typography conforming to ecology and
population demography publication figures (e.g. reseeding viability and
population growth rate).

## Usage

``` r
theme_cli_ecology(base_size = 11, base_family = "")
```

## Arguments

- base_size:

  Base font size in points (default 11).

- base_family:

  Base font family.

## Value

A ggplot2 theme.
