# Natural Connectivity of an Adjacency Matrix

Calculates the spectral natural connectivity \\\bar{\lambda}\\ of an
unweighted or thresholded network adjacency matrix. Natural connectivity
characterizes redundancy of alternative pathways and global network
stability.

## Usage

``` r
calc_natural_connectivity(adj)
```

## Arguments

- adj:

  Symmetric numeric adjacency matrix.

## Value

Numeric natural connectivity score.
