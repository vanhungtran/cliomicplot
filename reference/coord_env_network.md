# Grammar Coordinate System for Coupled Environmental Networks

Enforces a fixed 1:1 circular aspect ratio with standard viewport
boundaries.

## Usage

``` r
coord_env_network(xlim = c(-7.4, 7.4), ylim = c(-7.4, 7.4))
```

## Arguments

- xlim:

  Vector of length 2 specifying horizontal bounds (default
  `c(-7.4, 7.4)`).

- ylim:

  Vector of length 2 specifying vertical bounds (default
  `c(-7.4, 7.4)`).

## Value

A `coord_fixed` object.
