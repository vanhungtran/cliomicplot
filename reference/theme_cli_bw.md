# Standard Black-and-White Theme for Laboratory Exploration

Standard Black-and-White Theme for Laboratory Exploration

## Usage

``` r
theme_cli_bw(base_size = 11, base_family = "")
```

## Arguments

- base_size:

  Base font size in points (default 11).

- base_family:

  Base font family.

## Value

A ggplot2 theme.
